# hardwired-control-unit

本项目用于计算机组成原理实验，内容是一个硬布线控制器的 ABEL 源码。

硬布线控制器根据当前机器周期、节拍信号、指令码和状态信号，产生寄存器装载、存储器读写、程序计数器更新、ALU 数据通路选择等控制信号，用于驱动实验计算机完成取指、执行和停机等流程。

## 项目文件

| 文件 | 说明 |
|---|---|
| `CTL_EXP5.abl` | 硬布线控制器的 ABEL 源码 |
| `ctl_1.lst` | ABEL 工具生成的列表文件，用于查看展开后的逻辑表达式 |

## 主要信号

| 类型 | 信号 |
|---|---|
| 输入信号 | `CLR`、`W1`、`W2`、`W3`、`W4`、`T1`、`MF`、`IR4`-`IR7`、`SWC`、`SWB`、`SWA`、`C` |
| 状态信号 | `RUN`、`ST0`、`MF1`、`SST0` |
| 输出控制信号 | `LDIR`、`LDPC`、`LDER`、`LDAR1`、`LDAR2`、`LDDR1`、`LDDR2`、`LRW`、`WRD`、`PC_INC`、`PC_ADD`、`ALU_BUS`、`SW_BUS`、`RS_BUS` 等 |

## 支持的指令/流程

源码中定义了以下控制流程和指令宏：

| 宏 | 含义 |
|---|---|
| `PR1`、`PR2` | 取指和程序运行阶段 |
| `KRD1`、`KRD2` | 手动读流程 |
| `KWE1`、`KWE2` | 手动写流程 |
| `KLD1`、`KLD2` | 手动装载流程 |
| `KRR1`、`KRR2` | 手动运行/读寄存器流程 |
| `ADD`、`SUB`、`MUL`、`AND` | ALU 运算指令 |
| `LDA`、`STA` | 存储器访问指令 |
| `JMP`、`JC` | 跳转指令 |
| `STP` | 停机指令 |

## 使用方式

1. 使用实验指定的 ABEL/PLD 工具打开 `CTL_EXP5.abl`。
2. 选择与实验板一致的目标芯片型号。
3. 编译源码并生成列表文件、逻辑方程文件和烧录文件。
4. 将生成的烧录文件写入目标 PLD/CPLD。
5. 在实验板上按实验指导书验证各条指令和控制流程。

## 环境要求

需要根据课程实验环境准备：

| 项目 | 说明 |
|---|---|
| ABEL/PLD 编译工具 | 用于编译 `.abl` 源码 |
| 目标 PLD/CPLD 芯片 | 需要和源码中的引脚分配一致 |
| PLD 烧录器 | 用于把生成的烧录文件写入芯片 |
| 实验计算机/实验箱 | 用于验证控制器输出信号和指令执行流程 |

## 注意事项

`ctl_1.lst` 是工具生成文件，修改源码后需要重新生成，避免源码和列表文件不一致。

实际能否运行取决于目标芯片型号、实验箱接线、工具链版本和烧录结果。
